# Contract Dashboard

Приложение для отображения статистики контрактов и проектов.

## Доступные страницы

- **/** - Статистика проектов (ProjectDashboard)
- **/project.html** - Статистика проектов (ProjectDashboard)
- **/contract.html** - Статистика контрактов (ContractDashboard)

## Запуск

### Разработка
```bash
npm start
```

### Сборка
```bash
# Сборка всех страниц
npm run build

# Сборка только страницы контрактов
npm run build:contract
```

## Структура проекта

- `src/components/ProjectDashboard.js` - Компонент для отображения статистики проектов
- `src/components/ContractDashboard.js` - Компонент для отображения статистики контрактов
- `src/Project.js` - Точка входа для страницы проектов
- `src/Contract.js` - Точка входа для страницы контрактов
- `src/index.js` - Основная точка входа (открывает статистику проектов)

## Конфигурация

Проект использует CRACO для настройки webpack с несколькими точками входа:
- `main` - основная страница (проекты)
- `project` - страница проектов
- `contract` - страница контрактов
